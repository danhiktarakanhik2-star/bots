ВТОРАЯ ПАРТИЯ: Minecraft Manhunt — модули 14–41

Содержимое этого ZIP намеренно отделено от предыдущей партии. Здесь нет основной базы, индекса v1 и файлов manhunt_01–manhunt_13; старые файлы не включены и не смешаны с новыми.

Всего внутри: 30 файлов — 28 тематических обучающих модулей manhunt_14–manhunt_41, индекс и этот README.

Объём только 28 обучающих модулей:
- 120 975 символов, включая пробелы и знаки;
- 101 102 символа после исключения всех пробельных знаков, запятых и точек.

Подсчёт выполнен по Unicode code points в тексте файлов; строгий вариант исключает все whitespace, не только обычный пробел. Индекс и README в указанный объём не входят.

Начни с manhunt_training_index_v2_ru.md. Ссылки в индексе работают после распаковки в одну папку. Все синтетические сценарии обозначены как учебные; механики проверяй на точной Java/Bedrock версии и ruleset своего сервера.
