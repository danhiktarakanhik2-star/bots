# Вторая партия Manhunt — 28 новых модулей

Это **отдельная новая партия** к уже прочитанным файлам. Она не включает основную базу и файлы `manhunt_01`–`manhunt_13`. В архиве должны быть только модули `manhunt_14`–`manhunt_41`, этот индекс и короткий манифест.

## Объём новой обучающей части

28 модулей (`manhunt_14`–`manhunt_41`) содержат **120 975 символов с пробелами** и **101 102 символа после исключения всех пробельных знаков, запятых и точек**. То есть требование «не менее 100 000» выполняется даже при строгом подсчёте, где не считаются и переносы строк. Подсчёт сделан скриптом по UTF-8 тексту до упаковки; индекс и README в это число не включены.

## Как применять пакет

- Для RAG загружай 3–6 документов под конкретную роль и фазу, не весь архив на каждый ход.
- Для обучения используй примеры как поведенческие шаблоны и связывай их с реальными логами/результатами игры.
- Сценарии без ссылок на фактический replay — учебные, не стенограммы Dream.
- Проверяй Java/Bedrock, версию и ruleset перед применением конкретной механики.
- «Идеально» достигается только после тестов на реальном API и новых seed’ах; текст сам не даёт боту управление или скрытые наблюдения.

Первоисточники и протокол фактического чтения находятся также в [модуле 12 исходной партии](manhunt_12_sources_ingestion_ru.md). Вторая партия намеренно хранится отдельно, чтобы не смешивать её с уже прочитанными материалами.
